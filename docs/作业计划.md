## 2. 关键数值（已算好，并互相自洽）

### 2.1 定时器时钟从哪来（F103C8T6）

```
HSE 8 MHz ──PLL×9──> SYSCLK = 72 MHz
                      ├─ AHB  = 72 MHz
                      ├─ APB1 = 36 MHz（÷2）  ← TIM2/3/4 挂这里
                      └─ APB2 = 72 MHz（÷1）

规则：定时器挂在 APB1 上，且 APB1 分频 ≠ 1  →  定时器时钟 = APB1 × 2 = 72 MHz
（以 CubeMX 时钟树里显示的数字为准）
```

### 2.2 1 ms 周期怎么配

公式（题目给的）：

```
(PSC + 1) × (ARR + 1) / 定时器时钟 = 0.001 s
```

取 **PSC = 71**、**ARR = 999**：

```
(71 + 1) × (999 + 1) / 72 000 000
= 72 × 1000 / 72 000 000
= 72 000 / 72 000 000
= 0.001 s  ✅ 1 ms
```

> 物理含义：PSC=71 → 计数时钟 72 MHz / 72 = **1 MHz**（每 1 µs 数一次）；
> ARR=999 → 数 **1000** 次溢出一次 → 1000 µs = **1 ms** ✅

### 2.3 IWDG 超时怎么算

公式：`超时 = (Reload + 1) × 分频 / LSI`

F103 的 LSI 按手册约 **40 kHz**（C 板/A 板是 32 kHz）：

```
(1249 + 1) × 64 / 40 000 = 80 000 / 40 000 = 2.000 s  ✅
```

### 2.4 为什么第 3 题 tick 涨到约 2000 就归零

```
2 s 超时 ÷ 1 ms 一拍 = 2000 拍  →  复位  →  启动代码清全局变量  →  tick 归 0
```

题目说的"涨到约 2000 归零"，就是这么来的 ✅

### 2.5 PC13 的细节

- 蓝板的板载 LED：阳极经电阻接 3.3V，阴极接 PC13 → **输出低电平点亮** ✅（和题目一致）；
- PC13 属于**备份域**引脚，驱动能力小：**最大约 3 mA**，输出速度限制 → CubeMX 里 **Speed 选 Low**。
